# Surface brief: `app/subscription-app.tsx`

## State

- `locked`: 用户已明确要求登录前与登录后 UI 保持一致。
- `mode`: operate。
- `task`: 快速查看订阅支出、续费日期和状态，并完成新增、续费、取消与分析。

## Product truth

- 这是个人订阅账本，不是企业 BI 后台。
- 金额、续费日期、当前状态的视觉权重高于装饰。
- 登录后沿用登录前「夜航账本」的哑黑背景、白色读数、紫红主操作与低频光晕。
- 不改订阅接口、账号隔离、同步和操作逻辑。

## Visual direction

- 背景：`#050608`，内容面板：`#0b0e14`，边界：白色 10% 透明度。
- 主操作：紫色到玫红的短渐变；普通状态以白色、灰色和单一语义色表达。
- 关键数字使用制表数字；标题和正文统一无衬线字体。
- 圆角维持 12–16px；卡片使用边界或环境影其中一种，不堆叠玻璃装饰。
- 页面进入使用一次模糊消散与轻微上移；常规交互控制在约 220–280ms。

## Responsive contract

- 桌面端保留固定侧栏与四项摘要。
- 900px 以下移除侧栏、启用底部导航。
- 620px 以下摘要改为单列，弹窗贴底且操作区保持高对比。
- 键盘焦点使用紫色 3px 外轮廓；减少动态偏好下关闭动画。

## Acceptance

- 登录前和登录后的背景、主色、字体、卡片材质与动效属于同一视觉系统。
- 深色状态下正文与输入内容清晰可读。
- 新增、日历、分析和账号弹窗不再出现浅色旧样式。
- 原有订阅管理功能与 API 行为不变。
