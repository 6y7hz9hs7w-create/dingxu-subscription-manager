# 订序微信小程序

这是“订序”的微信原生小程序版本，使用微信云开发完成微信身份登录和数据存储。

完整版本记录见 [CHANGELOG.md](./CHANGELOG.md)。

## 3.1 官方处理指引

- 续费处理中心和日历详情新增“去处理”，覆盖腾讯视频、爱奇艺、优酷、芒果TV、哔哩哔哩大会员、QQ音乐、网易云音乐、喜马拉雅、微信读书无限卡、百度网盘、叮咚买菜绿卡、夸克网盘、WPS会员、迅雷会员、淘宝88VIP、京东PLUS、美团会员、饿了么超级吃货卡、剪映VIP和盒马X会员。
- 操作指引会根据微信支付、支付宝、Apple 订阅或其他渠道显示可靠路径；只有核验过 appId 的服务才允许标注“去官方小程序”，其余服务提供可复制的精确步骤，不伪造直达入口。
- 用户从官方渠道返回后，需要主动确认“已续费、已关闭自动续费、暂未完成”，订序才会改变订阅状态。
- 已移除最小化体验统计开关及相关事件记录；登录时会自动清理旧用户资料中的历史体验统计字段。

## 3.0 逐项续费处理

- 微信续费提醒直接进入“我的—续费处理”，单项定位对应订阅，多项按续费日期逐一处理并显示进度。
- 每项任务可选择已续费、暂停、确认已在服务商取消，或延后 1/3/7 天；延后只移动应用内任务，不改变账单日期和统计，也不重复发送微信提醒。
- 确认续费默认沿用当前金额与周期；金额变化时可直接修改，美元订阅会按更新时汇率换算人民币。
- 暂停后停止支出、日历和提醒统计且不自动归档；恢复时可重新选择续费日期。
- 确认取消后保留 7 天撤销时间再转入历史记录；整批处理完成后汇总结果和预计未来 12 个月减少的支出。
- 云端通过原账期校验续费操作，避免重复点击或网络重试把续费日连续顺延。

## 服务版订阅助手

- 总览支持按服务名称、分类或备注快速查找订阅，筛选过程不发起额外云端请求。
- 订阅清单可按续费日期、金额或服务名称排序，并能与搜索条件同时使用。
- 状态筛选可单独查看生效、待确认、暂停或计划取消的订阅，空结果支持一键重置。
- 订阅清单支持一次选择最多 20 项并批量暂停或恢复；取消和删除仍需逐项确认，避免误操作。
- 界面采用轻量液态玻璃设计，结构面板、底部导航和日历详情具有透明层次与高光效果；长列表保持轻量渲染。
- 每项订阅可以记录微信支付、支付宝、Apple 订阅或其他扣款渠道。
- 标记取消前会显示对应渠道的关闭自动续费路径，并要求用户确认已在服务商处完成关闭。
- 取消确认日、最近一次续费/暂停/恢复等处理结果会随订阅保存，在总览和日历中可直接核对。
- 修改订阅金额时自动保留上一次价格和调价日期，并在总览、日历详情与续费处理中心直接提示价格变化。
- 消费分析会汇总最近调价对每月支出的增减影响，并逐项展示调整前后月均价格。
- “我的”新增默认收起的续费处理中心，集中汇总待确认、未来 7/30 天续费、计划取消和暂停订阅，避免在多个页面逐项查找。
- 点击处理中心的三类统计即可展开对应任务；再次点击同一分类恢复全部任务。
- 折叠状态会直接提示当前最高优先级，任务列表同步显示逾期天数、续费倒计时、归档倒计时或暂停保留状态。
- 未来 30 天内未开启、已发送需重开或发送失败的提醒会优先提示，并可在处理中心直接申请微信提醒授权。
- 处理中心收起时不会渲染完整任务列表，提醒列表也避免重复传输；订阅接近 100 项上限时仍保持轻量切换。
- 处理中心可直接完成续费确认、取消、暂停、恢复、删除和延后 1/3/7 天；只有编辑订阅时才进入表单。
- “我的”新增默认收起的最近操作记录，集中展示续费、暂停、恢复、取消和延后处理结果及日期，不新增额外云端请求。
- 导出的图片与 CSV 报告包含扣款渠道；全部订阅 CSV 还会列出关闭自动续费确认日。
- 订序不会代替用户操作第三方服务；最终价格、有效期和服务状态以服务商页面为准。

## 2.2 美元订阅与自动换算

- 添加或编辑订阅时可以选择人民币或美元计价；美元金额会按添加时获取的汇率自动折算为人民币。
- 原始美元金额、换算汇率和汇率日期会随订阅保存，后续编辑不会丢失原始账单信息。
- 总览、续费日历、消费分析和提醒统计统一使用人民币口径，同时保留原始美元金额供用户核对。
- 添加页会提前加载汇率，并在客户端和云函数端合并重复请求、短时复用结果，减少切换美元时的等待。
- CSV 报告同时导出原始币种、原始金额、美元兑人民币汇率和折合人民币金额。

## 2.1 智能与自定义订阅图标

- 输入未收录的服务名称时会自动联网查找 App 图标，并在表单内提供最多三个候选。
- 用户选择联网候选后，图标会保存到当前微信用户的专属云存储目录；放弃使用的临时图标会自动清理。
- 添加或编辑订阅时可从相册选择图片，并优先裁剪为 1:1 方形图标。
- 自定义图标会覆盖内置服务图标，可随时更换或恢复默认。
- 图片只在保存订阅时上传，单张限制 5MB；首页、日历、分析和个人中心会统一显示。
- 发布前需在小程序隐私保护指引中声明“选中的照片或视频”，用途为“用于用户自定义订阅服务图标”。
- 图标按微信 OPENID 分目录存储，云函数会校验文件归属并清理被替换的旧图标。

## 2.0 使用体验升级

- “我的”页统一汇总已开启、尚未授权、已发送需重新开启和提醒失败四种状态。
- 每项生效订阅都能直接申请或重新申请微信订阅消息授权。
- 提醒按单项订阅分别开启：每授权一次只对应一次推送，发送后需要用户再次开启，不提供每月统一汇总推送。
- 云函数会记录发送成功与失败结果；一次性提醒发送后会明确提示为下一周期重新开启。
- 导出中心支持将全部订阅、本月计划支出和年度订阅预估生成分页图片或 UTF-8 CSV 文件。
- 页面共享同一份订阅摘要缓存；日历和个人中心只向渲染层发送实际展示字段，导出引擎按需加载。
- 定时提醒仅接受云端定时触发器调用，客户端不能伪造定时事件。
- 头像使用当前微信身份对应的专属云存储路径，云函数仅接受和清理属于该身份的头像文件。
- 月底和闰日续费会自动顺延到目标月份的最后一天，不会错误跨月。
- 日历会按月付或年付周期展示后续续费日期；点击日期可查看当天明细，并直接标记到期取消或恢复。
- 添加订阅支持按分类选择常用服务、显示本地品牌图标，并使用完整色盘自定义标记颜色。
- 总览、分析和个人中心的统计卡片均可点击查看对应明细。

## 视觉焕新

- 使用系统无衬线字体、暖灰背景、深绿主视觉和统一圆角卡片，不包含外部商业字体。
- 总览突出月均支出、年度预估和近期扣款；日历、分析和个人中心采用一致的信息层级。
- 添加订阅改为“选择服务、设置账单、提醒与标记”三步结构。
- 保留共享数据缓存和请求合并，页面切换不清空现有内容，也不使用入场动画造成闪烁。

## 登录与数据安全

- 小程序启动后调用云函数，云函数通过 `cloud.getWXContext()` 获取当前用户的 `OPENID`，用于识别微信账号。
- 客户端不传入、也不能修改数据所属用户；所有读写都在云函数中使用服务端获得的 `OPENID` 过滤。
- 头像使用 `button open-type="chooseAvatar"` 由用户主动选择，昵称使用 `input type="nickname"` 由用户主动确认；资料与服务端识别的微信账号绑定。
- 不申请手机号，不在小程序代码中保存 `AppSecret`。
- 当前版本只维护微信小程序，不提供网页版绑定或同步入口。

## 微信续费提醒

续费提醒使用微信“小程序订阅消息”，不会静默获取授权。用户为某项订阅点击“开启提醒”时才会出现微信授权弹窗；一次授权只对应该项订阅的一次服务通知，发送成功或失败后都会关闭本次提醒，需要用户再次主动开启。系统不会每月统一推送。

用户将订阅标记为“到期取消”后仍可随时恢复或手动删除。若 7 天内未恢复，每天 09:00 的云端检查会在归档日期到达后将记录转入历史归档；永久删除只由用户手动执行。归档记录不会参与支出、日历和提醒统计，也不会继续显示在总览清单；可从“我的 → 历史记录”查看、恢复或手动永久删除。

续费日已过但尚未处理的订阅会进入“待确认”，用户可以标记已续费、确认已在服务商取消，或延后 1、3、7 天处理。延后不会再次申请微信提醒；同一用户同一天有多项提醒时只发送一条汇总消息，避免连续打扰。

1. 登录小程序后台，进入“功能 → 订阅消息 → 公共模板库”，选择适合的“续费提醒”模板。
2. 当前使用模板 5171“会员到期提醒”，字段为到期时间 `time1` 和到期说明 `thing2`。
3. 复制模板 ID，填写到 `cloudfunctions/subscriptionService/index.js` 的 `RENEWAL_TEMPLATE_ID`。
4. 当前代码已按模板详情配置 `time1` 和 `thing2`；提醒显示对应服务名称、到期时间和预计金额。
5. 右键云函数 `subscriptionService`，选择“上传并部署：云端安装依赖”。部署时会同步订阅消息调用权限和每天 09:00 执行的定时触发器。
6. 重新编译并用真机添加订阅；允许订阅消息后，首页卡片会显示“微信续费提醒已开启”。

若模板 ID 尚未填写，小程序会明确显示“当前仅在小程序内显示续费日期”，不会声称已经开启微信推送。

## 发布前检查

- 在真机预览中添加一项订阅，确认日历和消费分析能读取同一份数据。
- 将测试订阅的续费日设为提醒天数后的日期，确认订阅消息授权弹窗和定时云函数日志正常。
- 为一项订阅开启提醒，手动运行定时云函数后确认只收到该项的一条消息，状态变为“已发送、需要重新开启”；再次运行定时任务不应重复发送。
- 使用另一个微信账号打开，确认看不到第一个账号的数据。
- 在小程序后台更新隐私保护指引，勾选“用户信息（微信昵称、头像）”；说明用途为展示账号个人中心并区分用户资料。
- 上传代码并提交微信审核。正式上传需要小程序管理员扫码，因此必须在已登录的微信开发者工具中完成。
